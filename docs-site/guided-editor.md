# Guided Editor

Guided Mode keeps common fields visible and hides lower-level wiring fields such as runtime IDs. It does not remove runtime behavior.

Use:

- `Conditioned Branch` for checks.
- `Set Condition` for actions and side effects.
- `Reward` quest nodes for quest actions.
- `Branch` or `Condition` quest nodes for quest checks.

Validate and save graph assets before packaging.
