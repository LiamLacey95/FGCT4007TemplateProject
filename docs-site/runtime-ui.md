# Runtime UI

Default widgets:

- `/DialogQuestSystem/UI/WBP_DQSDialogue_Default`
- `/DialogQuestSystem/UI/WBP_DQSQuestTracker_Default`
- `/DialogQuestSystem/UI/WBP_DQSQuestLog_Default`

Duplicate them into project content before heavy customization.

`DQSDialogueWidgetBase` exposes helpers for text, choices, portrait, speaker style, theme, and `GetVoiceSound`. Voice sounds also play automatically when speech lines are presented.
